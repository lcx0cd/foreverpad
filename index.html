ForeverPad — 魔兽世界永恒手柄配置文件生成器

给魔兽世界永恒（测试服）玩家：任意手柄 → 网页学按键 → 生成 gamecontrollerdb.txt。也适用于正式服 / 经典。

1. 输入与学习（先按几下键让浏览器标记连接）

0 / 16
点「开始学习」后，图上对应的键会闪烁，照着按即可。
原始输入（B0–B14 / A0–A9，调试用；平时不用看）
示意图会在学完按键后按你的映射高亮；摇杆点位置跟随实时输入。 没高亮说明还没学习这个键（或该键不在标准映射里）。

按顺序学按键（每步停 1 秒）

点「开始学习」，然后按提示逐个按手柄。
说明：按物理位置认键；摇杆向右/上推到底；扳机按到底。

2. 生成映射

复制 → 粘贴进对应文件；下载 → 文件名已经正确，直接覆盖原文件即可。
手动安装（最稳，不需要自动化）
1. 点上面的「复制映射」，或用「下载 gamecontrollerdb.txt」覆盖原文件
2. 用文本编辑器打开下面对应的文件（没有就新建）
3. 粘贴到文件末尾；如果已有同一设备（同 GUID）的行，替换那一行
4. 保存，然后完全重启 WoW（不是 /reload）

3. 为什么需要这一层？

macOS 的「游戏控制器」只认 Xbox/PS/Switch/MFi；杂牌 DInput 只能当普通 HID。Chrome 能直接读原始输入，WoW 内置 SDL2，给一条映射即可。本工具把「读手柄 → 学按键 → 生成映射」做成网页。

AI 排查：复制「AI 诊断包」发给 AI，即可根据设备与学习结果判断问题。
